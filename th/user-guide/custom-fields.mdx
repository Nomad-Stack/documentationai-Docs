## ฟิลด์ที่กำหนดเองช่วยให้คุณบันทึกรายละเอียดที่ธุรกิจของคุณต้องการ

เพิ่มฟิลด์ของคุณเองให้กับลูกค้า ผลิตภัณฑ์ ใบแจ้งหนี้ ใบเสนอราคา และใบแจ้งหนี้ขาเข้า เพื่อให้ทุกบันทึกตรงกับวิธีการทำงานของคุณใช้ฟิลด์ที่กำหนดเองสำหรับบันทึกภายใน หมายเลขอ้างอิง หมวดหมู่ ลิงก์ การคำนวณ ไฟล์แนบ และข้อความที่สร้างขึ้น AI โดยไม่ต้องเปลี่ยนขั้นตอนการทำงานมาตรฐานของคุณ

<Callout kind="info">

ฟิลด์ที่กำหนดเองเป็นฟิลด์เฉพาะของบริษัทฟิลด์ที่คุณสร้างจะพร้อมใช้งานเฉพาะในบัญชีบริษัทของคุณ และสำหรับประเภทเอนทิตีที่คุณกำหนดเท่านั้น

</Callout>

## วิธีการทำงานของฟิลด์แบบกำหนดเอง

ฟิลด์แบบกำหนดเองสร้างขึ้นจากสองส่วน: **คำจำกัดความของฟิลด์** และก **ค่าฟิลด์**.ข้อกำหนดจะควบคุมตำแหน่งที่ฟิลด์ปรากฏ ประเภทอินพุตที่ฟิลด์ยอมรับ และไม่ว่าจะสามารถใช้ในตาราง แบบฟอร์ม หรือเทมเพลต PDF ได้หรือไม่ค่าคือข้อมูลจริงที่บันทึกไว้ในแต่ละระเบียน

คุณสร้างฟิลด์ตามประเภทเอนทิตี จากนั้นกรอกข้อมูลเมื่อคุณสร้างหรือแก้ไขเรกคอร์ดตัวอย่างเช่น คุณอาจเพิ่มฟิลด์หมวดหมู่ลูกค้าสำหรับลูกค้า ฟิลด์ SKU สำหรับผลิตภัณฑ์ หรือฟิลด์อ้างอิงโครงการสำหรับใบแจ้งหนี้

### ประเภทเอนทิตี

| ประเภทเอนทิตี | ใช้สำหรับ |
|---|---|
| `customer` | จัดเก็บรายละเอียดเพิ่มเติมเกี่ยวกับลูกค้า เช่น หมายเลขลูกค้า เว็บไซต์ วันที่เริ่มต้นใช้งาน หรือบันทึกภายใน |
| `product` | เพิ่มข้อมูลเมตาเฉพาะผลิตภัณฑ์ เช่น SKU หมวดหมู่ น้ำหนัก ราคาซื้อ หรือการรับรอง |
| `invoice` | บันทึกรายละเอียดใบแจ้งหนี้ เช่น การอ้างอิงโครงการ บันทึกการส่งมอบ สถานะการอนุมัติ หรือมูลค่าที่คำนวณได้ |
| `quote` | ติดตามข้อมูลเฉพาะของใบเสนอราคา เช่น หมายเลขการแก้ไข บันทึกความถูกต้อง หรือขั้นตอนการขาย |
| `incoming_invoice` | บันทึกข้อมูลเมตาการเรียกเก็บเงินของซัพพลายเออร์ เช่น การอ้างอิงใบเสร็จรับเงิน ช่องการอนุมัติ หรือเอกสารประกอบที่แนบมา |

<Callout kind="tip">

เก็บชื่อฟิลด์เฉพาะสำหรับประเภทเรกคอร์ดสนามแบบว่า. `sku` สมเหตุสมผลกับผลิตภัณฑ์ในขณะที่ `project_reference` ง่ายต่อการรักษาในใบแจ้งหนี้

</Callout>

## ประเภทฟิลด์

เลือกประเภทฟิลด์ตามประเภทข้อมูลที่คุณต้องการให้ผู้ใช้ป้อนหรือสร้าง

| ประเภทฟิลด์ | คำอธิบาย |
|---|---|
| `text` | การป้อนข้อความบรรทัดเดียว |
| `multiline` | พื้นที่ข้อความหลายบรรทัดสำหรับบันทึกย่อที่ยาวขึ้น |
| `email` | การป้อนที่อยู่อีเมล |
| `url` | การป้อนข้อมูลเว็บไซต์หรือลิงก์ |
| `phone` | การป้อนหมายเลขโทรศัพท์ |
| `number` | การป้อนจำนวนเต็ม |
| `decimal` | การป้อนตัวเลขทศนิยม |
| `amount` | การป้อนจำนวนสกุลเงิน |
| `percent` | การป้อนตัวเลขแสดงเป็นเปอร์เซ็นต์ |
| `date` | เครื่องมือเลือกวันที่ |
| `datetime` | ตัวเลือกวันที่และเวลา |
| `boolean` | ช่องทำเครื่องหมายที่มีสถานะใช่หรือไม่ใช่ |
| `dropdown` | ฟิลด์แบบเลือกครั้งเดียวพร้อมตัวเลือกที่กำหนดไว้ล่วงหน้า |
| `multiselect` | ฟิลด์แบบเลือกหลายรายการพร้อมตัวเลือกที่กำหนดไว้ล่วงหน้า |
| `autonumber` | กำหนดหมายเลขตามลำดับโดยอัตโนมัติ |
| `lookup` | เชื่อมโยงไปยังเอนทิตีอื่น |
| `formula` | ฟิลด์ที่คำนวณตามนิพจน์ |
| `attachment` | ช่องอัพโหลดไฟล์ |
| `ai` | AI - ฟิลด์ข้อความที่สร้างขึ้นตามพรอมต์ที่บันทึกไว้ |

## การกำหนดค่าภาคสนาม

การตั้งค่าฟิลด์จะควบคุมการตรวจสอบ การมองเห็น และการจัดลำดับกำหนดค่าตัวเลือกเหล่านี้เมื่อคุณสร้างฟิลด์ จากนั้นอัปเดตในภายหลังหากเวิร์กโฟลว์ของคุณเปลี่ยนแปลง

<ParamField body="is_required" param-type="boolean" required="false" show-location="false">

ทำให้ฟิลด์บังคับเมื่อผู้ใช้กรอกแบบฟอร์มบันทึก

</ParamField>

<ParamField body="is_unique" param-type="boolean" required="false" show-location="false">

ป้องกันค่าที่ซ้ำกันสำหรับฟิลด์นั้นในเรกคอร์ดของประเภทเอนทิตีเดียวกัน

</ParamField>

<ParamField body="show_in_table" param-type="boolean" required="false" show-location="false">

แสดงฟิลด์เป็นคอลัมน์ในมุมมองรายการสำหรับประเภทเอนทิตีนั้น

</ParamField>

<ParamField body="show_in_form" param-type="boolean" required="false" show-location="false">

แสดงฟิลด์ในการสร้างและแก้ไขแบบฟอร์มการตั้งค่านี้เปิดใช้งานตามค่าเริ่มต้น

</ParamField>

<ParamField body="available_in_pdf" param-type="boolean" required="false" show-location="false">

ทำให้ฟิลด์พร้อมใช้งานสำหรับเทมเพลต PDF การตั้งค่านี้เปิดใช้งานตามค่าเริ่มต้น

</ParamField>

<ParamField body="sort_order" param-type="integer" required="false" show-location="false">

ควบคุมลำดับของฟิลด์แบบกำหนดเองภายในประเภทเอนทิตีที่เลือก

</ParamField>

## การสร้างฟิลด์ที่กำหนดเอง

สร้างฟิลด์จากตัวจัดการฟิลด์ที่กำหนดเองในการตั้งค่าวิธีที่เร็วที่สุดคือกำหนดป้ายกำกับและพิมพ์ก่อน จากนั้นจึงเปิดเฉพาะตัวเลือกที่คุณต้องการ

<Steps>
  <Step title="เปิดฟิลด์ที่กำหนดเอง" icon="settings">

  ลงชื่อเข้าใช้ NomadBill และเปิดพื้นที่ฟิลด์ที่กำหนดเองในการตั้งค่าของคุณ

  เลือกประเภทเอนทิตีที่คุณต้องการขยาย เช่น ลูกค้า ผลิตภัณฑ์ ใบแจ้งหนี้ ใบเสนอราคา หรือใบแจ้งหนี้ขาเข้า

  </Step>
  <Step title="สร้างคำจำกัดความของฟิลด์" icon="plus">

  เพิ่มฟิลด์ใหม่และป้อน **ฉลาก** ที่คนในทีมของคุณจะจดจำได้ NomadBill ยังสร้างไฟล์ **สำคัญ** สำหรับฟิลด์จากป้ายกำกับนั้น

  เลือก **ประเภทฟิลด์** ที่ตรงกับข้อมูลที่คุณต้องการรวบรวมหากคุณเลือก `dropdown` หรือ `multiselect` เพิ่มตัวเลือกที่คุณต้องการให้ผู้ใช้เลือก

  </Step>
  <Step title="กำหนดค่าการมองเห็นและการตรวจสอบ" icon="edit">

  เปิดตัวเลือกที่คุณต้องการสำหรับฟิลด์นั้น เช่น จำเป็น ไม่ซ้ำกัน มองเห็นได้ในแบบฟอร์ม มองเห็นได้ในตาราง หรือมีอยู่ในเทมเพลต PDF

  หากคุณต้องการให้ช่องปรากฏก่อนหรือหลังช่องอื่นๆ ให้ปรับลำดับการจัดเรียงก่อนที่จะบันทึก

  </Step>
  <Step title="บันทึกและทดสอบสนาม" icon="check-circle">

  บันทึกฟิลด์ จากนั้นเปิดเรกคอร์ดของประเภทเอนทิตีเดียวกันและยืนยันว่าอินพุตปรากฏขึ้นในตำแหน่งที่คุณคาดหวัง

  ความสำเร็จดูเหมือนฟิลด์ที่แสดงในแบบฟอร์มหรือมุมมองตารางตามตัวเลือกที่คุณเปิดใช้งาน

  </Step>
</Steps>

<Callout kind="alert">

คุณไม่สามารถเปลี่ยนประเภทของฟิลด์ได้หลังจากที่สร้างแล้วหากคุณต้องการประเภทอื่น ให้สร้างฟิลด์ใหม่และย้ายเวิร์กโฟลว์ของคุณไปยังฟิลด์ใหม่นั้น

</Callout>

## การใช้ฟิลด์ที่กำหนดเองในเรกคอร์ด

หลังจากที่คุณสร้างฟิลด์ NomadBill จะแสดงฟิลด์นั้นในเรกคอร์ดของประเภทเอนทิตีนั้นเมื่อใด `show_in_form` ถูกเปิดใช้งานผู้ใช้สามารถป้อนค่าในขณะที่สร้างบันทึกใหม่หรืออัปเดตในภายหลังจากมุมมองแก้ไข

ค่าฟิลด์ที่กำหนดเองจะถูกบันทึกไว้ต่อบันทึกฟิลด์ระดับผลิตภัณฑ์ใช้กับผลิตภัณฑ์เท่านั้น และฟิลด์ระดับใบแจ้งหนี้ใช้กับใบแจ้งหนี้เท่านั้นหากมีการทำเครื่องหมายฟิลด์ไว้ด้วย `show_in_table` ค่าสามารถปรากฏในมุมมองรายการเพื่อช่วยให้คุณสแกนและกรองบันทึกได้รวดเร็วยิ่งขึ้น

ฟิลด์แบบกำหนดเองยังรองรับรูปแบบการแก้ไขหน้ารายละเอียดอีกด้วยซึ่งทำให้มีประโยชน์สำหรับข้อมูลที่คุณไม่ได้ป้อนล่วงหน้าเสมอไป เช่น บันทึกภายใน วันที่ติดตามผล หรือเอกสารแนบสนับสนุน

## ฟิลด์หมายเลขอัตโนมัติ

ใช้ฟิลด์ตัวเลขอัตโนมัติเมื่อคุณต้องการ IDs ตามลำดับที่ NomadBill กำหนดโดยอัตโนมัติวิธีนี้ใช้ได้ผลดีกับหมายเลขลูกค้า หมายเลขผลิตภัณฑ์ ข้อมูลอ้างอิงภายใน หรือ IDs ที่มีโครงสร้างอื่นๆ ที่ไม่ควรป้อนด้วยตนเอง

<Callout kind="info">

ช่องป้อนหมายเลขอัตโนมัติรองรับตัวเลือกการตั้งค่าสามตัวเลือก:

- **คำนำหน้า** เพิ่มข้อความหน้าตัวเลข เช่น `K-` หรือ `P-`.
- **ช่องว่างภายใน** เพิ่มศูนย์นำหน้าเพื่อให้ได้ความกว้างคงที่
- **เริ่ม** กำหนดหมายเลขแรกตามลำดับ

หมายเลขลูกค้าอาจเริ่มต้นที่ `K-1000` ในขณะที่หมายเลขผลิตภัณฑ์อาจใช้ `P-00001`.

</Callout>

แต่ละครั้งที่มีการสร้างเรกคอร์ดใหม่ NomadBill จะกำหนดหมายเลขถัดไปในลำดับสำหรับฟิลด์นั้นซึ่งจะช่วยลดการเรียงลำดับหมายเลขที่ซ้ำกันและช่วยให้บันทึกมีความสอดคล้องกัน

## ฟิลด์สูตร

ใช้ฟิลด์สูตรเมื่อควรคำนวณค่าแทนที่จะป้อนด้วยตนเองฟิลด์สูตรมีประโยชน์สำหรับผลรวม มาร์กอัป ค่าตามเปอร์เซ็นต์ หรือการคำนวณเฉพาะเรกคอร์ดที่ขึ้นอยู่กับฟิลด์อื่น

นิพจน์สูตรสามารถอ้างอิงค่าตัวเลขในตัวและฟิลด์แบบกำหนดเองได้ตัวแปรที่ใช้ได้ได้แก่:

- `subtotal`
- `vat_percentage`
- `total`
- `unit_price`
- `custom.KEY`

ตัวอย่างเช่นคุณสามารถใช้ `custom.discount_rate * subtotal / 100` เพื่อคำนวณจำนวนส่วนลดเมื่อใด `discount_rate` ถูกจัดเก็บไว้ในฟิลด์ที่กำหนดเองอื่นค่าสูตรจะถูกคำนวณโดยอัตโนมัติเมื่อ NomadBill บันทึกค่าฟิลด์ที่กำหนดเอง

<Callout kind="tip">

ทำให้คีย์ฟิลด์สูตรเรียบง่ายและคาดเดาได้ เพื่อให้อ่านนิพจน์ได้ง่ายขึ้นที่สำคัญเช่น `discount_rate` ใช้งานง่ายกว่าใน `custom.discount_rate` มากกว่ารูปแบบการตั้งชื่อที่ยาวหรือไม่สอดคล้องกัน

</Callout>

## ฟิลด์ที่สร้างโดย AI

ใช้ฟิลด์ AI ที่สร้างขึ้นเมื่อคุณต้องการให้ NomadBill เขียนข้อความให้คุณตามพร้อมท์ที่บันทึกไว้สิ่งนี้มีประโยชน์สำหรับการสรุปภายใน คำอธิบายฉบับร่าง บันทึกการติดตามผล หรือข้อความมาตรฐานที่ควรสร้างจากข้อมูลบันทึก

ก่อนที่คุณจะสามารถใช้ฟิลด์ AI ได้ ให้สร้างพร้อมต์ AI ในตัวจัดการฟิลด์แบบกำหนดเองจากนั้นเชื่อมต่อพร้อมท์นั้นกับฟิลด์เมื่อคุณสร้างคำจำกัดความของฟิลด์ในบันทึก ผู้ใช้สามารถสร้างหรือสร้างข้อความใหม่ได้โดยตรงจากอินพุตฟิลด์

NomadBill รองรับโมเดล AI เหล่านี้สำหรับการแจ้งเตือน:

- `google/gemini-3-flash-preview`
- `google/gemini-2.5-flash`
- `google/gemini-2.5-pro`
- `openai/gpt-5-mini`
- `openai/gpt-5`

AI - ฟิลด์ที่สร้างขึ้นจะจัดเก็บเอาต์พุตข้อความตรวจสอบเนื้อหาที่สร้างขึ้นก่อนนำไปใช้ในเอกสารที่ติดต่อกับลูกค้า

## ฟิลด์ที่กำหนดเองในเทมเพลต PDF

ทำให้ฟิลด์พร้อมใช้งานในเอาต์พุต PDF โดยการเปิดใช้งาน `available_in_pdf` บนคำจำกัดความของสนามหลังจากนั้น คุณสามารถวางฟิลด์ในเทมเพลตเอกสารของคุณ และใช้ค่าที่กำหนดเองเมื่อสร้างใบแจ้งหนี้ ใบเสนอราคา หรือ ไฟล์ PDF อื่นๆ

หากคุณวางแผนที่จะรวมฟิลด์ที่กำหนดเองในเอกสารที่พิมพ์ ให้ตั้งค่าฟิลด์ก่อนที่จะสรุปเทมเพลตของคุณซึ่งจะทำให้โครงสร้างเทมเพลตของคุณมีเสถียรภาพและหลีกเลี่ยงการทำซ้ำในภายหลัง

อ่าน [เทมเพลต PDF](/th/user-guide/pdf-templates) สำหรับการตั้งค่าเทมเพลตและตัวเลือกเค้าโครงเอกสาร
