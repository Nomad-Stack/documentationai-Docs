## ออกแบบเค้าโครง PDF แบบกำหนดเองสำหรับเอกสารของคุณ

เทมเพลต PDF ช่วยให้คุณควบคุมลักษณะของใบแจ้งหนี้ ใบเสนอราคา และเอกสารขาเข้าเมื่อคุณดูตัวอย่าง ส่งออก หรือส่งคุณสามารถเริ่มจากเค้าโครงเปล่า เลือกการออกแบบที่สร้างไว้ล่วงหน้า หรือนำเข้าเทมเพลต JSON จากนั้นปรับผลลัพธ์ในตัวแก้ไขแบบลากและวาง

<Callout kind="info">

จัดการเทมเพลตใน **การตั้งค่า → เทมเพลต**.NomadBill เก็บรายการเทมเพลตแยกต่างหากสำหรับใบแจ้งหนี้ ใบเสนอราคา และเอกสารขาเข้า เพื่อให้คุณสามารถออกแบบเอกสารแต่ละประเภทแยกกัน

</Callout>

## เทมเพลต PDF ทำงานอย่างไร

เทมเพลต PDF แต่ละเทมเพลตจะจัดเก็บเค้าโครงแบบเต็มสำหรับเอกสารประเภทเดียวซึ่งรวมถึงโครงสร้างหน้า บล็อกข้อความ ตาราง รูปภาพ และสไตล์ที่ใช้ในการสร้าง PDF สุดท้าย

เมื่อคุณสร้างหรือแก้ไขใบแจ้งหนี้ ใบเสนอราคา หรือเอกสารขาเข้า คุณสามารถใช้เทมเพลตเริ่มต้นสำหรับประเภทเอกสารนั้นหรือเลือกเทมเพลตที่บันทึกไว้อื่นวิธีนี้ช่วยให้คุณมีวิธีที่สม่ำเสมอในการจัดเก็บเอกสารในแต่ละวันให้เป็นแบรนด์ ขณะเดียวกันก็ยังสามารถจัดวางรูปแบบอื่นได้เมื่อจำเป็น

NomadBill รองรับเอกสารสามประเภท:

| ประเภทเอกสาร | ใช้สำหรับ | ที่คุณเลือกมัน |
| --- | --- | --- |
| ใบแจ้งหนี้ | ใบแจ้งหนี้ขาออกที่คุณส่งให้กับลูกค้า | แบบฟอร์มใบแจ้งหนี้และดูตัวอย่าง |
| อ้าง | ใบเสนอราคาหรือข้อเสนอที่คุณส่งก่อนที่จะออกใบแจ้งหนี้ | แบบฟอร์มใบเสนอราคาและดูตัวอย่าง |
| เข้ามา | ใบแจ้งหนี้ขาเข้า ใบเรียกเก็บเงินของซัพพลายเออร์ หรือใบเสร็จรับเงิน | กระแสเอกสารขาเข้า |

## ประเภทเอกสาร

เทมเพลตจะถูกจัดกลุ่มตามประเภทเอกสาร เนื่องจากแต่ละประเภทมีวัตถุประสงค์ที่แตกต่างกัน และอาจต้องใช้คำหรือเน้นเค้าโครงที่แตกต่างกัน

| พิมพ์ | ชื่อทั่วไปใน PDF | การใช้งานทั่วไป |
| --- | --- | --- |
| `invoice` | ใบแจ้งหนี้ | เรียกเก็บเงินลูกค้าสำหรับงานที่ทำเสร็จแล้วหรือสินค้าที่ส่งมอบ |
| `quote` | อ้าง | ส่งข้อเสนอราคาก่อนเริ่มงาน |
| `incoming` | ใบเสร็จรับเงินหรือใบแจ้งหนี้ขาเข้า | บันทึกค่าใช้จ่ายของซัพพลายเออร์หรือใบเสร็จรับเงินที่อัปโหลด |

<Callout kind="tip">

หากคุณต้องการเค้าโครงที่แตกต่างกันสำหรับเอกสารประเภทเดียวกัน ให้สร้างเทมเพลตหลายเทมเพลตและตั้งค่าเทมเพลตหนึ่งเป็นค่าเริ่มต้นคุณยังคงสามารถเลือกเทมเพลตอื่นสำหรับเอกสารเฉพาะได้เมื่อจำเป็น

</Callout>

## การสร้างเทมเพลต

คุณสามารถสร้างเทมเพลตได้สามวิธี: เริ่มว่างเปล่า เริ่มจากแกลเลอรี หรือนำเข้าไฟล์ JSON ที่มีอยู่

<Steps>
  <Step title="สร้างเทมเพลตเปล่า" icon="plus">

  เปิด **การตั้งค่า → เทมเพลต**เลือกแท็บประเภทเอกสาร จากนั้นสร้างเทมเพลตใหม่แล้วเลือก **ว่างเปล่า**.

  เทมเพลตเปล่าเริ่มต้นจากเค้าโครงเริ่มต้นของ NomadBill สำหรับประเภทเอกสารนั้นนี่คือตัวเลือกที่เร็วที่สุดเมื่อคุณต้องการการควบคุมเต็มรูปแบบแต่ยังคงต้องการแมปฟิลด์มาตรฐานที่จำเป็นไว้แล้ว

  </Step>
  <Step title="เริ่มจากแกลเลอรี่" icon="book-open">

  เปิด **การตั้งค่า → เทมเพลต**เลือกแท็บประเภทเอกสาร จากนั้นสร้างเทมเพลตใหม่แล้วเลือก **แกลเลอรี่**.

  เลือกหนึ่งในเจ็ดเทมเพลตในตัวหากคุณต้องการเค้าโครงที่เสร็จสมบูรณ์ซึ่งคุณสามารถปรับเปลี่ยนได้นี่คือจุดเริ่มต้นที่ดีที่สุดเมื่อคุณต้องการเค้าโครงแบบมืออาชีพโดยไม่ต้องสร้างทุกส่วนตั้งแต่ต้น

  </Step>
  <Step title="นำเข้าเทมเพลต JSON" icon="upload">

  เปิด **การตั้งค่า → เทมเพลต**เลือกแท็บประเภทเอกสาร จากนั้นสร้างเทมเพลตใหม่แล้วเลือก **นำเข้าจาก JSON**.

  อัพโหลด `.json` ไฟล์ที่มีโครงสร้างเทมเพลตที่ถูกต้องใช้เส้นทางนี้หากคุณมีไฟล์เทมเพลตที่เข้ากันได้อยู่แล้ว และต้องการใช้ซ้ำในบริษัทหรือสภาพแวดล้อมต่างๆ

  </Step>
</Steps>

## แกลเลอรีเทมเพลต

NomadBill มีเทมเพลตที่สร้างไว้ล่วงหน้าเจ็ดแบบที่คุณสามารถใช้เป็นจุดเริ่มต้นได้

| แม่แบบ | สไตล์ | ดีที่สุดสำหรับ |
| --- | --- | --- |
| คลาสสิค | ค่าเริ่มต้นที่สมดุลด้วยส่วนหัวสีของแบรนด์ | ใบแจ้งหนี้และใบเสนอราคาสำหรับวัตถุประสงค์ทั่วไป |
| ทันสมัย | แถบด้านบนสีที่มีชื่อตัวหนา | เค้าโครงที่ก้าวไปข้างหน้าของแบรนด์ |
| น้อยที่สุด | เค้าโครงขาวดำโดยไม่มีการเน้นสี | เอกสารที่เรียบง่ายและมีหมึกน้อย |
| สีขาว | ทำความสะอาดเค้าโครงที่สามารถพิมพ์ได้ด้วยบล็อกวิธีการชำระเงิน | ใบแจ้งหนี้อย่างเป็นทางการและขั้นตอนการพิมพ์ |
| สีฟ้า | เน้นสีน้ำเงินพร้อมแถวเต็มทั้งหมด | ผลรวมและส่วนสรุปที่มีคอนทราสต์สูง |
| สีเขียว | แถบเน้นเสียงด้านซ้ายสีเขียว | เค้าโครงทางเลือกที่มีตราสินค้า |
| สง่างาม | ชื่อขนาดใหญ่พร้อมตารางสีเทาเรียบๆ | เอกสารพบปะลูกค้าขัดเกลา |

## การแก้ไขเทมเพลต

เครื่องมือแก้ไขเทมเพลตจะเปิดขึ้นในตัวออกแบบแบบเต็มหน้าจอ เพื่อให้คุณสามารถสร้างและปรับเค้าโครงได้อย่างชัดเจนคุณสามารถลากฟิลด์ไปยังตำแหน่ง ปรับขนาด เปลี่ยนข้อความ และปรับแต่งโครงสร้างภาพโดยไม่ต้องแก้ไข JSON ที่ซ่อนอยู่ด้วยมือ

ประเภทฟิลด์ที่ใช้ได้ ได้แก่ ข้อความ ข้อความหลายตัวแปร ตาราง รายการ เส้น รูปร่าง รูปภาพ ลายเซ็น วันที่ ช่องทำเครื่องหมาย กลุ่มตัวเลือก รหัส QR และบาร์โค้ดสิ่งนี้ให้ความยืดหยุ่นเพียงพอแก่คุณในการสร้างเค้าโครงใบแจ้งหนี้มาตรฐานตลอดจนการออกแบบเอกสารที่ปรับแต่งได้มากขึ้น

ผู้ใช้ส่วนใหญ่จะใช้เวลาในการปรับตำแหน่ง ระยะห่าง ป้ายกำกับ และการนำเสนอตารางหากคุณคงชื่อฟิลด์มาตรฐานไว้ NomadBill จะยังคงเติมฟิลด์เหล่านั้นโดยอัตโนมัติเมื่อสร้าง PDF

<Callout kind="info">

โดยทั่วไปรายการรายการเอกสารจะแสดงผลผ่านทาง `items` สนามตารางหากคุณลบหรือเปลี่ยนชื่อฟิลด์นั้น รายการสินค้าจะไม่ปรากฏใน PDF ที่สร้างขึ้นอีกต่อไป

</Callout>

## ฟิลด์มาตรฐาน

NomadBill เติมชื่อฟิลด์เฉพาะโดยอัตโนมัติเมื่อแสดงผล PDF คงชื่อเหล่านี้ไว้ไม่เปลี่ยนแปลง หากคุณต้องการให้แอปพลิเคชันเก็บข้อมูลเอกสารการแมปลงในเทมเพลต

| ชื่อฟิลด์ | ประกอบด้วย |
| --- | --- |
| `company_logo` | รูปภาพโลโก้บริษัทของคุณ |
| `company_name` | ชื่อที่แสดงของบริษัทของคุณ |
| `company_address` | ที่อยู่บริษัทของคุณ มักจะเป็นแบบหลายบรรทัด |
| `company_vat` | ป้ายกำกับและค่า VAT หรือภาษี ID ของคุณ |
| `doc_title` | ชื่อเอกสาร เช่น ใบแจ้งหนี้ ใบเสนอราคา หรือใบเสร็จรับเงิน |
| `doc_number` | หมายเลขเอกสาร |
| `doc_date` | วันที่ออกฉลากและมูลค่า |
| `doc_due_date` | ป้ายวันที่ครบกำหนดและมูลค่า |
| `bill_to_label` | ป้ายส่วนลูกค้า |
| `customer_name` | ชื่อลูกค้า |
| `customer_address` | ที่อยู่ลูกค้า |
| `items` | ตารางรายการสินค้า |
| `subtotal_label` | ป้ายกำกับผลรวมย่อย |
| `subtotal` | จำนวนเงินรวมย่อย |
| `vat_label` | ป้ายกำกับ VAT |
| `vat_amount` | จำนวน VAT |
| `total_label` | ป้ายกำกับทั้งหมด |
| `total` | จำนวนเงินทั้งหมด |
| `bank_label` | ป้ายกำกับส่วนรายละเอียดการชำระเงิน |
| `bank_details` | คำแนะนำของธนาคารหรือการชำระเงิน |
| `signature` | รูปภาพลายเซ็น |
| `footer` | ข้อความส่วนท้าย |

## สีของแบรนด์

เทมเพลตแกลเลอรีสามารถใช้สีแบรนด์บริษัทของคุณโดยอัตโนมัติ NomadBill อ่านสีหลักและสีรองของคุณจากการตั้งค่าบริษัท และใช้สีเหล่านั้นเพื่อเปลี่ยนสีองค์ประกอบเทมเพลตที่รองรับ

วิธีนี้ได้ผลดีที่สุดเมื่อคุณต้องการการสร้างแบรนด์ที่สอดคล้องกันในใบแจ้งหนี้และใบเสนอราคาทั้งหมดโดยไม่ต้องอัปเดตทุกบล็อกข้อความ ส่วนหัว หรือองค์ประกอบการเน้นด้วยตนเองโดยปกติแล้วสีที่ถูกเน้นจะถูกนำไปใช้กับส่วนหัว แท่ง ผลรวม หรือการไฮไลท์พื้นหลัง ทั้งนี้ขึ้นอยู่กับเทมเพลต

เค้าโครงของแบรนด์บางแบบยังรองรับการทำให้ข้อความเป็นสีดำในขณะที่ยังคงใช้ชุดสีแบรนด์ของคุณในพื้นที่เน้นเสียงใช้แนวทางดังกล่าวหากสีแบรนด์ของคุณสว่างหรือหากความสามารถในการอ่านมีความสำคัญมากกว่าการจัดรูปแบบข้อความแบบเต็มสี

## เทมเพลตหลายภาษา

เทมเพลตรองรับสี่ภาษา: DE , EN , FR และ ESการเปลี่ยนแปลงภาษาจะอัปเดตป้ายกำกับในตัว เช่น ชื่อเอกสาร ป้ายกำกับวันที่ ผลรวมย่อย VAT ผลรวม และข้อความมาตรฐานอื่นๆ ที่ใช้ในเทมเพลตเริ่มต้น

NomadBill แปลป้ายกำกับเทมเพลตแยกจากเค้าโครงนั่นหมายความว่าคุณสามารถสลับภาษาได้โดยไม่สูญเสียตำแหน่ง การเว้นวรรค สี หรือการเปลี่ยนแปลงการออกแบบอื่น ๆ ที่คุณทำในตัวแก้ไข

หากคุณทำงานในหลายภาษา ให้สร้างเทมเพลตหนึ่งเทมเพลตต่อภาษา เมื่อคุณต้องการควบคุมถ้อยคำและการจัดรูปแบบอย่างสมบูรณ์หากเค้าโครงยังคงเหมือนเดิม คุณสามารถใช้การออกแบบเดิมซ้ำได้และอาศัยป้ายกำกับที่แปลตามความเหมาะสม

## ฟิลด์ที่กำหนดเองในเทมเพลต

ช่องที่กำหนดเองทำให้คุณสามารถเพิ่มค่าบริษัท ลูกค้า หรือเอกสารเฉพาะให้กับ ไฟล์ PDF ของคุณได้ในเทมเพลต ค่าเหล่านี้ใช้ชื่อฟิลด์ในรูปแบบ `cf_{entity}_{key}`.

ตัวอย่างเช่น ฟิลด์ที่กำหนดเองซึ่งเชื่อมโยงกับใบแจ้งหนี้สามารถแมปกับชื่อฟิลด์ เช่น `cf_invoice_project_reference`.ฟิลด์แบบกำหนดเองระดับลูกค้าเป็นไปตามรูปแบบเดียวกันกับเซ็กเมนต์เอนทิตีของลูกค้า

อ่าน [ฟิลด์ที่กำหนดเอง](/th/user-guide/custom-fields) ก่อนที่จะเพิ่มตัวยึดเหล่านี้เพื่อให้คีย์ฟิลด์และชื่อฟิลด์เทมเพลตของคุณอยู่ในแนวเดียวกัน

<Callout kind="tip">

หากช่องที่กำหนดเองปรากฏเป็นช่องว่างใน PDF ให้ตรวจสอบก่อนว่ามีช่องดังกล่าวอยู่ คีย์ตรงกันทุกประการ และชื่อช่องในเทมเพลตใช้ค่าที่คาดไว้ `cf_{entity}_{key}` ลวดลาย.

</Callout>

## การตั้งค่าเทมเพลตเริ่มต้น

เอกสารแต่ละประเภทสามารถมีเทมเพลตเริ่มต้นได้หนึ่งเทมเพลตเทมเพลตเริ่มต้นจะถูกใช้โดยอัตโนมัติ เว้นแต่คุณจะเลือกเทมเพลตอื่นในแบบฟอร์มเอกสารหรือหน้าจอแสดงตัวอย่าง

หากต้องการเปลี่ยนค่าเริ่มต้น ให้เปิด **การตั้งค่า → เทมเพลต**ค้นหาเทมเพลตในแท็บประเภทเอกสารที่ถูกต้องแล้วใช้ **ตั้งค่าเริ่มต้น**.เทมเพลตที่อัปเดตจะกลายเป็นจุดเริ่มต้นใหม่สำหรับเอกสารประเภทนั้นทั่วทั้งบริษัทของคุณ

สิ่งนี้มีประโยชน์เมื่อคุณกำลังเปิดตัวโครงร่างที่รีเฟรชตั้งค่าเทมเพลตใหม่เป็นค่าเริ่มต้นก่อน จากนั้นจึงเก็บเทมเพลตเก่าไว้สำหรับกรณีพิเศษหรือความสอดคล้องในอดีต
