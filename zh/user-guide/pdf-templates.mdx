## 为您的文档设计自定义 PDF 布局

PDF 模板可让您控制发票、报价和传入文档在预览、导出或发送时的外观。您可以从空白布局开始，选择预构建的设计，或导入 JSON 模板，然后在拖放编辑器中调整结果。

<Callout kind="info">

在**设置 → 模板**中管理模板。 NomadBill 为发票、报价和传入文档保留单独的模板列表，因此您可以独立设计每种文档类型。

</Callout>

## PDF 模板如何工作

每个 PDF 模板都存储一种文档类型的完整布局。其中包括用于生成最终 PDF 的页面结构、文本块、表格、图像和样式。

创建或编辑发票、报价或传入文档时，您可以使用该文档类型的默认模板或选择不同的已保存模板。这为您提供了一种一致的方式来保持日常文档的品牌形象，同时仍然允许在需要时使用备用布局。

NomadBill支持三种文档类型：

|文件类型|用于 |在哪里选择它 |
| --- | --- | --- |
|发票|您发送给客户的发票 |发票表格和预览 |
|报价 |您在开具发票之前发送的报价或报价 |报价表格和预览 |
|传入 |进项发票、供应商账单或收据 |传入文档流 |

## 文档类型

模板按文档类型分组，因为每种类型都有不同的目的，并且可能需要不同的措辞或布局重点。

|类型 | PDF 中的典型标题 |常用|
| --- | --- | --- |
| `invoice` |发票|向客户收取已完成工作或已交付货物的费用 |
| `quote` |报价 |在工作开始前发送价格建议 |
| `incoming` |收据或进项发票|记录供应商费用或上传收据|

<Callout kind="tip">

如果您希望同一文档类型有不同的布局，请创建多个模板并将其中一个设置为默认模板。您仍然可以在需要时为特定文档选择另一个模板。

</Callout>

## 创建模板

您可以通过三种方式创建模板：从空白开始、从库开始或导入现有的 JSON 文件。

<Steps>
  <Step title="创建一个空白模板" icon="plus">

打开**设置→模板**，选择文档类型选项卡，然后创建一个新模板并选择**空白**。

空白模板从 NomadBill 该文档类型的默认布局开始。当您想要完全控制但仍希望已映射所需的标准字段时，这是最快的选项。

  </Step>
  <Step title="从画廊开始" icon="book-open">

打开 **设置 → 模板**，选择文档类型选项卡，然后创建一个新模板并选择 **图库**。

如果您想要一个可以调整的成品布局，请选择七个内置模板之一。当您想要专业的布局而不是从头开始构建每个部分时，这是最好的起点。

  </Step>
  <Step title="导入 JSON 模板" icon="upload">

打开**设置 → 模板**，选择文档类型选项卡，然后创建一个新模板并选择**从 JSON 导入**。

上传包含有效模板结构的 `.json` 文件。如果您已有兼容的模板文件并希望在公司或环境中重复使用它，请使用此路径。

  </Step>
</Steps>

## 模板库

NomadBill 包括七个预构建模板，您可以将其用作起点。

|模板|风格|最适合 |
| --- | --- | --- |
|经典|平衡默认与品牌颜色标题 |通用发票和报价|
|现代|带有粗体标题的彩色顶部栏 |品牌前卫布局|
|最小 |没有彩色强调的单色布局 |简单、低墨水文档 |
|白色|带有付款方式块的干净的可打印布局 |正式发票和打印工作流程 |
|蓝色|蓝色点缀，总行填充 |高对比度总计和摘要部分 |
|绿色|绿色左强调栏 |替代品牌布局|
|优雅|带有微妙灰色表格的大标题|完善的面向客户的文档 |

## 编辑模板

模板编辑器在全屏设计器中打开，以便您可以直观地构建和调整布局。您可以将字段拖动到位、调整其大小、更改文本并优化视觉结构，而无需手动编辑底层 JSON。

可用的字段类型包括文本、多变量文本、表格、列表、线条、形状、图像、签名、日期、复选框、单选组、QR 代码和条形码。这为您提供了足够的灵活性来创建标准发票布局以及更多定制的文档设计。

大多数用户会花时间调整位置、间距、标签和表格呈现。如果您保持标准字段名称不变，则 NomadBill 在生成 PDF 时会继续自动填充这些字段。

<Callout kind="info">

文档项目列表通常通过 `items` 表字段呈现。如果删除或重命名该字段，明细项将不再出现在生成的 PDF 中。

</Callout>

## 标准字段

NomadBill 在渲染 PDF 时会自动填充特定字段名称。如果您希望应用程序继续将文档数据映射到模板中，请保持这些名称不变。

|字段名称 |包含 |
| --- | --- |
| `company_logo` |贵公司标志图像|
| `company_name` |您的公司显示名称 |
| `company_address` |您的公司地址，通常是多行 |
| `company_vat` |您的 VAT 或税号标签和价值 |
| `doc_title` |文件标题，例如发票、报价或收据 |
| `doc_number` |文件编号|
| `doc_date` |发行日期标签和值 |
| `doc_due_date` |到期日标签和值 |
| `bill_to_label` |客户部分标签|
| `customer_name` |客户名称 |
| `customer_address` |客户地址 |
| `items` |明细项表|
| `subtotal_label` |小计标签|
| `subtotal` |小计金额 |
| `vat_label` | VAT 标签 |
| `vat_amount` | VAT 金额 |
| `total_label` |总标签 |
| `total` |总金额 |
| `bank_label` |付款详情部分标签 |
| `bank_details` |银行或付款指示 |
| `signature` |签名图片|
| `footer` |页脚文本|

## 品牌颜色

图库模板可以自动应用您公司的品牌颜色。 NomadBill 从公司设置中读取主要颜色和次要颜色，并使用它们对支持的模板元素重新着色。

当您希望所有发票和报价中的品牌保持一致而无需手动更新每个文本块、标题或强调元素时，此方法效果最佳。根据模板的不同，强调色通常应用于标题、条形、总计或背景突出显示。

一些品牌布局还支持将文本保持为黑色，同时仍将品牌调色板应用于重点区域。如果您的品牌颜色较浅或者可读性比全彩文本样式更重要，请使用这种方法。

## 多语言模板

模板支持四种语言：DE、EN、FR 和 ES。语言更改会更新内置标签，例如文档标题、日期标签、小计、VAT、总计以及默认模板中使用的其他标准文本。

NomadBill 将模板标签与布局本身分开翻译。这意味着您可以切换语言，而不会丢失位置、间距、颜色或在编辑器中所做的其他设计更改。

如果您使用多种语言工作，当您需要完全控制措辞和格式时，请为每种语言创建一个模板。如果布局保持不变，您可以重复使用相同的设计并在适当的情况下依赖翻译的标签。

## 模板中的自定义字段

自定义字段允许您将公司、客户或文档特定的值添加到 PDF。在模板中，这些值使用 `cf_{entity}_{key}` 格式的字段名称。

例如，与发票关联的自定义字段可以使用 `cf_invoice_project_reference` 等字段名称进行映射。客户级自定义字段遵循与客户实体细分相同的模式。

添加这些占位符之前请阅读[自定义字段](/zh/user-guide/custom-fields)，以便您的字段键和模板字段名称保持对齐。

<Callout kind="tip">

如果自定义字段在 PDF 中显示为空白，请首先确认该字段存在、键完全匹配，并且模板中的字段名称使用预期的 `cf_{entity}_{key}` 模式。

</Callout>

## 设置默认模板

每种文档类型可以有一个默认模板。除非您在文档表单或预览屏幕上选择不同的模板，否则系统会自动使用默认模板。

要更改默认值，请打开 **设置 → 模板**，在正确的文档类型选项卡中找到模板，然后使用 **设置默认值**。更新后的模板成为整个公司该文档类型的新起点。

当您推出刷新的布局时，这非常有用。首先将新模板设置为默认模板，然后保留旧模板以用于特殊情况或历史一致性。
