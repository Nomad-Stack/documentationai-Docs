## Recent Updates

Stay informed about the latest improvements to Nomadbill. We release updates regularly to enhance invoicing, multi-currency support, and bookkeeping automation. Check the app version in your settings to ensure you have the newest features.

<Callout kind="info">
  Enable auto-updates in your Nomadbill app settings to receive new versions seamlessly.
</Callout>

<Update label="2024-12-15" description="v2.4.0" tags={["feature", "improvement"]}>

## New Features

- Added support for 5 new currencies: TRY, UAH, ZAR, AED, and NGN—now totaling 49 currencies with live ECB rates.
- Introduced recurring invoice templates with customizable schedules (weekly, bi-weekly, quarterly).
- New dashboard widget for profit/loss overview across multiple currencies.

## Improvements

- Faster reconciliation of bank inflows with a 40% speed boost.
- Enhanced mobile app support for invoice approvals on the go.

## Bug Fixes

- Fixed FX rate locking issue for invoices over `{100,000}` EUR equivalent.
- Resolved notification delays for payment reminders.

</Update>

<Update label="2024-12-01" description="v2.3.1" tags={["bugfix", "security"]}>

## Bug Fixes

- Patched security vulnerability in webhook endpoints—always use HTTPS for integrations.
- Corrected auto-reconciliation for mixed-currency expenses (e.g., EUR flights booked in USD).
- Fixed export to CSV where dates shifted for non-GMT timezones.

## Improvements

- Better error messages for invalid IBAN validation during client setup.

</Update>

<Update label="2024-11-20" description="v2.3.0" tags={["feature", "breaking"]}>

## New Features

- One-click US tax form generation (1099-NEC) for US clients.
- Integrated Stripe and Wise payouts directly from the dashboard.
- Bulk invoice actions: send, void, or archive up to 50 at once.

## Breaking Changes

- Updated API webhook format—verify your endpoint handles `event_type` as string instead of number.

## Improvements

- Optimized database queries for users with `{>500}` monthly invoices.

</Update>

## How to Update

Follow these steps to get the latest version.

<Steps>
  <Step title="Check Version" icon="info">
    Open Nomadbill app → Settings → About. Note your current version (e.g., `v2.4.0`).
  </Step>
  <Step title="Enable Updates" icon="toggle-right">
    Go to Settings → Updates → Toggle "Auto-update" on.
  </Step>
  <Step title="Restart App" icon="refresh-cw">
    Fully close and reopen the app to apply changes.
  </Step>
</Steps>
