## Mantenha os dados dos seus clientes num único local

Os clientes armazenam as informações de contacto que reutiliza ao longo do fluxo de faturação. Adicione cada cliente uma vez em `/customers`, mantenha os respetivos dados atualizados e volte a utilizar esses registos quando criar faturas e orçamentos.

Os proprietários e os membros da equipa da empresa podem gerir clientes no espaço de trabalho da empresa. A lista de clientes está ordenada alfabeticamente por nome e a tabela apresenta os campos de contacto padrão, além de quaisquer campos personalizados configurados para aparecerem na tabela.

## Campos de cliente

Cada registo de cliente inclui os campos de contacto principais abaixo.

<ParamField body="name" param-type="string" required="true" show-location="false">

O nome de apresentação do cliente. O NomadBill exige este campo e utiliza-o como etiqueta principal na lista de clientes.

</ParamField>

<ParamField body="email" param-type="string" required="false" show-location="false">

O endereço de e-mail do cliente.

</ParamField>

<ParamField body="phone" param-type="string" required="false" show-location="false">

O número de telefone do cliente.

</ParamField>

<ParamField body="address" param-type="string" required="false" show-location="false">

A morada do cliente. Na caixa de diálogo de criação e edição, este campo utiliza uma área de texto com várias linhas para poder introduzir uma morada de faturação completa.

</ParamField>

<Callout kind="info">

Por predefinição, a lista de clientes apresenta **nome**, **e-mail** e **telefone**. Também apresenta os campos personalizados de clientes cuja visibilidade na tabela esteja ativada.

</Callout>

## Criar um cliente

Adicione um cliente a partir da página de clientes e, em seguida, preencha os dados de contacto que pretende reutilizar mais tarde.

<Steps>
  <Step title="Abrir a página de clientes" icon="users">

  Aceda a `/customers` no seu espaço de trabalho.

  Deverá ver uma tabela de clientes ordenada por nome. Se já tiver criado campos personalizados de clientes com a visibilidade na tabela ativada, essas colunas também aparecem aqui.

  </Step>
  <Step title="Iniciar um novo registo de cliente" icon="plus">

  Crie um novo cliente a partir da ação da página.

  O NomadBill abre uma caixa de diálogo de criação com os campos padrão de cliente e quaisquer campos personalizados atribuídos à entidade `customer`.

  </Step>
  <Step title="Introduzir os dados obrigatórios e opcionais" icon="edit">

  Preencha as informações do cliente:

  - O **Nome** é obrigatório.
  - O **E-mail** é opcional.
  - O **Telefone** é opcional.
  - A **Morada** é opcional e suporta texto com várias linhas.
  - Os **Campos personalizados** aparecem quando os tiver configurado para clientes.

  Os espaços de trabalho de demonstração poderão já incluir campos predefinidos, como `kundennummer`, `kundenkategorie`, `website`, `kunden_seit`, `notizen_intern`, `praeferierte_sprachen` e `newsletter`.

  </Step>
  <Step title="Guardar e verificar o resultado" icon="check-circle">

  Guarde o cliente.

  Depois de guardar, o cliente aparece na vista de lista na posição alfabética correta. Se um campo personalizado estiver configurado para aparecer em tabelas, o respetivo valor também aparece como uma coluna na linha.

  </Step>
</Steps>

## Editar e eliminar clientes

Atualize um cliente a partir da mesma caixa de diálogo utilizada para a criação. Pode alterar os campos de contacto padrão e quaisquer campos personalizados de cliente atribuídos em qualquer altura.

Quando elimina um cliente, o NomadBill pede-lhe que confirme a ação antes de remover o registo. Elimine com cuidado se utiliza as informações desse cliente no seu processo de faturação habitual.

## Utilizar clientes em faturas

Os clientes foram concebidos para poupar tempo ao criar faturas. Em vez de voltar a introduzir os dados de contacto em cada documento, seleciona ou reutiliza um registo de cliente existente.

As faturas armazenam o nome do cliente no campo `customer_name`. Isto significa que o registo de cliente fornece o nome de origem que utiliza nos fluxos de faturação, mantendo a lista de clientes organizada num único local.

<Callout kind="tip">

Configure os clientes antes de começar a enviar faturas regularmente. Uma lista de clientes organizada acelera a criação de faturas e reduz as inconsistências de nomes entre documentos.

</Callout>

## Campos personalizados para clientes

Os campos personalizados de clientes permitem-lhe acompanhar informações para além dos campos de contacto padrão. O NomadBill atribui estes campos ao tipo de entidade `customer`, o que significa que aparecem nos formulários de cliente e, quando configurados, na tabela de clientes.

Utilize campos personalizados para dados como números internos de cliente, categorias, sites, datas de início, preferências de idioma, notas ou estado de adesão à newsletter. Os dados de demonstração poderão incluir campos como `kundennummer` como numeração automática, `kundenkategorie` como lista pendente, `website` como URL, `kunden_seit` como data, `notizen_intern` como texto com várias linhas, `praeferierte_sprachen` como seleção múltipla e `newsletter` como booleano.

Para obter instruções de configuração e consultar os tipos de campo, veja [Campos personalizados](/pt/user-guide/custom-fields).
