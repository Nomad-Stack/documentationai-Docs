**Adicionar um Cliente**

Crie registros de cliente no NomadBill para reutilizá-los em faturas e orçamentos. O NomadBill organiza os clientes alfabeticamente por nome, o que torna os registros salvos fáceis de encontrar mais tarde.

<Passos>
  <Passo título="Abrir a página dos Clientes">

    A partir do seu painel, abra **Clientes**. A lista de clientes mostra o nome, o e-mail e o telefone de cada cliente, assim como quaisquer campos personalizados configurados para aparecerem na tabela.

  </Passo>
  <Passo título="Adicionar um novo cliente">

    Clique em **Adicionar cliente** para abrir o formulário de criação do cliente.

  </Passo>
  <Passo título="Preencher os detalhes do cliente">

    Complete o registro do cliente:

    - **Nome** — obrigatório
    - **E-mail** — opcional
    - **Telefone** — opcional
    - **Endereço** — opcional

    Se seu espaço de trabalho usa campos personalizados para clientes, o formulário também inclui esses campos.

  </Passo>
  <Passo título="Salvar o cliente">

    Clique em **Salvar** para criar o cliente. O novo cliente aparece na lista em ordem alfabética por nome.

  </Passo>
</Passos>

<Nota informativa>

Use clientes salvos ao criar faturas preenchendo o campo `customer_name` com um registro de cliente existente. Se precisar armazenar informações extras, adicione campos personalizados para o tipo de entidade `customer` e escolha se eles aparecem na tabela do cliente.

</Nota informativa>
