## Configurez la façon dont chaque entreprise apparaît dans NomadBill

Utilisez Paramètres pour gérer les détails de l'entreprise qui apparaissent sur les factures, les devis et les exportations PDF. Vous pouvez mettre à jour le profil de votre entreprise, télécharger un logo, choisir les couleurs de la marque, gérer les modèles PDF et définir des champs personnalisés pour l'entreprise active.

<Callout kind="info">

Si vous gérez plusieurs sociétés, NomadBill stocke les paramètres séparément pour chaque société.

</Callout>

## Profil de l'entreprise

Le profil de votre entreprise contrôle les informations commerciales affichées sur les documents générés. Gardez ces détails précis afin que les factures et les devis incluent les informations correctes sur l’expéditeur.

Mettez à jour le profil de votre entreprise avec des détails tels que :

- **Nom de l'entreprise** – indiqué comme nom de votre entreprise sur les documents
- **Adresse** — utilisée dans le bloc d'adresse de l'entreprise sur les factures et les devis
- **TVA ID** — utilisé pour les détails du document liés à TVA
- **Logo** — disponible pour les modèles de marque PDF

Lorsque vous exportez ou prévisualisez des documents, NomadBill utilise ces informations sur la société dans la sortie PDF. Cela inclut des valeurs telles que le nom de l'entreprise, l'adresse de l'entreprise, les détails TVA et l'emplacement du logo dans les modèles pris en charge.

## Image de marque et couleurs

Les paramètres de marque contrôlent l'identité visuelle utilisée dans vos modèles PDF. Téléchargez votre logo et définissez les couleurs primaires et secondaires pour que les documents exportés restent alignés avec l'image de marque de votre entreprise.

Les couleurs primaires et secondaires sont stockées avec les paramètres de votre entreprise et peuvent être appliquées aux accents du modèle. Selon le modèle, NomadBill utilise ces couleurs pour les en-têtes, les surbrillances et autres éléments visuels dans les PDF générés.

<Callout kind="tip">

Certains modèles de marque conservent le corps du texte en noir et appliquent vos couleurs uniquement aux accents. Cela améliore la lisibilité tout en restant fidèle à votre marque.

</Callout>

### Configurer la marque

<Steps>
  <Step title="Ouvrez les paramètres de votre entreprise" icon="settings">

  Accédez aux **Paramètres** de l'entreprise que vous souhaitez mettre à jour. Si vous travaillez dans plusieurs entreprises, confirmez que vous modifiez la bonne entreprise avant d'apporter des modifications.

  </Step>
  <Step title="Mettre à jour les détails de l'entreprise" icon="edit">

  Saisissez ou vérifiez le **nom de votre entreprise**, votre **adresse** et votre **ID TVA**. Enregistrez les modifications afin que NomadBill puisse les utiliser dans les factures, les devis et les exportations PDF.

  Une mise à jour réussie signifie que les dernières informations sur votre entreprise apparaîtront la prochaine fois que vous prévisualiserez ou exporterez un document.

  </Step>
  <Step title="Téléchargez votre logo" icon="upload">

  Ajoutez le logo de votre entreprise dans la zone de marque des paramètres. Les modèles PDF pris en charge peuvent ensuite placer ce logo dans l'en-tête du document ou dans la section entreprise.

  Après le téléchargement, votre logo doit apparaître dans les aperçus des modèles de marque et dans les PDF exportés qui incluent un champ de logo.

  </Step>
  <Step title="Choisissez les couleurs de la marque" icon="palette">

  Définissez votre **couleur principale** et votre **couleur secondaire** pour l'entreprise. NomadBill utilise ces couleurs lors de l'application de la marque aux modèles PDF pris en charge.

  Après l'enregistrement, les modèles de marque doivent refléter les couleurs d'accent mises à jour dans les aperçus ou les documents générés.

  </Step>
</Steps>

## Modèles PDF

Les modèles PDF contrôlent la mise en page et le style de vos factures, devis et documents PDF entrants. Dans Paramètres, vous pouvez ouvrir la zone Modèles pour gérer les modèles pour différents types de documents.

NomadBill prend en charge les modèles de marque qui peuvent utiliser le logo et les couleurs de votre entreprise. Les modèles sont disponibles par type de document et vous pouvez choisir quel modèle doit servir de modèle par défaut.

Lisez le guide complet pour gérer les modèles, les valeurs par défaut et les options de personnalisation dans [Modèles PDF](/fr/user-guide/pdf-templates).

## Champs personnalisés

Les champs personnalisés vous permettent de stocker des informations supplémentaires relatives à l'entreprise ou au document qui ne correspondent pas aux champs par défaut. Utilisez-les lorsque votre flux de travail nécessite des étiquettes, des références ou des points de données internes supplémentaires.

Une fois configurés, les champs personnalisés peuvent prendre en charge des flux de documents plus personnalisés sans modifier le profil standard de votre entreprise. Pour les détails de configuration et d'utilisation, voir [Champs personnalisés](/fr/user-guide/custom-fields).

## Les paramètres sont stockés par entreprise

<Callout kind="info">

Lorsque vous changez d’entreprise, vous travaillez avec un ensemble de paramètres différent. Les détails du profil de l'entreprise, la marque, les modèles et les champs personnalisés ne sont pas automatiquement transférés d'une entreprise à l'autre.

</Callout>
