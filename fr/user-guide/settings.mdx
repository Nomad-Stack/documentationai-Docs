## Configurez la façon dont chaque entreprise apparaît dansNomadBill

Utilisez Paramètres pour gérer les détails de l'entreprise qui apparaissent sur les factures, les devis etPDFexportations. Vous pouvez mettre à jour le profil de votre entreprise, télécharger un logo, choisir les couleurs de la marque, gérerPDFmodèles et définissez des champs personnalisés pour la société active.

<Callout kind="info">

Si vous gérez plusieurs sociétés,NomadBillstocke les paramètres séparément pour chaque entreprise.

</Callout>

## Profil de l'entreprise

Le profil de votre entreprise contrôle les informations commerciales affichées sur les documents générés. Gardez ces détails précis afin que les factures et les devis incluent les informations correctes sur l’expéditeur.

Mettez à jour le profil de votre entreprise avec des détails tels que :

- **Nom de l'entreprise** – indiqué comme nom de votre entreprise sur les documents
- **Adresse** — utilisée dans le bloc d'adresse de l'entreprise sur les factures et les devis
- **VATID** — utilisé pourVAT-détails du document lié
- **Logo** — disponible pour les marquesPDFmodèles

Lorsque vous exportez ou prévisualisez des documents,NomadBillutilise ces informations sur l'entreprise dans lePDFsortir. Cela inclut des valeurs telles que le nom de l'entreprise, l'adresse de l'entreprise,VATdétails et placement du logo dans les modèles pris en charge.

## Image de marque et couleurs

Les paramètres de marque contrôlent l'identité visuelle utilisée dans votrePDFmodèles. Téléchargez votre logo et définissez les couleurs primaires et secondaires pour que les documents exportés restent alignés avec l'image de marque de votre entreprise.

Les couleurs primaires et secondaires sont stockées avec les paramètres de votre entreprise et peuvent être appliquées aux accents du modèle. Selon le modèle,NomadBillutilise ces couleurs pour les en-têtes, les surbrillances et autres éléments visuels dans les PDF générés.

<Callout kind="tip">

Certains modèles de marque conservent le corps du texte en noir et appliquent vos couleurs uniquement aux accents. Cela améliore la lisibilité tout en restant fidèle à votre marque.

</Callout>

### Configurer la marque

<Steps>
  <Step title="Ouvrez les paramètres de votre entreprise" icon="settings">

Accédez aux **Paramètres** de l'entreprise que vous souhaitez mettre à jour. Si vous travaillez dans plusieurs entreprises, confirmez que vous modifiez la bonne avant d'apporter des modifications.

  </Step>
  <Step title="Mettre à jour les détails de l'entreprise" icon="edit">

Saisissez ou vérifiez le **nom de votre entreprise**, votre **adresse** et **VATIDENTIFIANT**. Enregistrez les modifications afinNomadBillpeut les utiliser dans les factures, les devis etPDFexportations.

Une mise à jour réussie signifie que les dernières informations sur votre entreprise apparaîtront la prochaine fois que vous prévisualiserez ou exporterez un document.

  </Step>
  <Step title="Téléchargez votre logo" icon="upload">

Ajoutez le logo de votre entreprise dans la zone de marque des paramètres. SoutenuPDFles modèles peuvent ensuite placer ce logo dans l’en-tête du document ou dans la section entreprise.

Après le téléchargement, votre logo doit apparaître dans les aperçus des modèles de marque et dans les PDF exportés qui incluent un champ de logo.

  </Step>
  <Step title="Choisissez les couleurs de la marque" icon="palette">

Définissez votre **couleur principale** et votre **couleur secondaire** pour l'entreprise.NomadBillutilise ces couleurs lors de l'application de la marque aux supports pris en chargePDFmodèles.

Après l'enregistrement, les modèles de marque doivent refléter les couleurs d'accent mises à jour dans les aperçus ou les documents générés.

  </Step>
</Steps>

## PDFmodèles

PDFLes modèles contrôlent la mise en page et le style de vos factures, devis et documents PDF entrants. Dans Paramètres, vous pouvez ouvrir la zone Modèles pour gérer les modèles pour différents types de documents.

NomadBillprend en charge les modèles de marque qui peuvent utiliser le logo et les couleurs de votre entreprise. Les modèles sont disponibles par type de document et vous pouvez choisir quel modèle doit servir de modèle par défaut.

Lisez le guide complet pour gérer les modèles, les valeurs par défaut et les options de personnalisation dans [PDFmodèles](/fr/user-guide/pdf-templates).

## Champs personnalisés

Les champs personnalisés vous permettent de stocker des informations supplémentaires relatives à l'entreprise ou au document qui ne correspondent pas aux champs par défaut. Utilisez-les lorsque votre flux de travail nécessite des étiquettes, des références ou des points de données internes supplémentaires.

Une fois configurés, les champs personnalisés peuvent prendre en charge des flux de documents plus personnalisés sans modifier le profil standard de votre entreprise. Pour plus de détails sur la configuration et l'utilisation, voir [Champs personnalisés](/fr/user-guide/custom-fields).

## Les paramètres sont stockés par entreprise

<Callout kind="info">

Lorsque vous changez d’entreprise, vous travaillez avec un ensemble de paramètres différent. Les détails du profil de l'entreprise, la marque, les modèles et les champs personnalisés ne sont pas automatiquement transférés d'une entreprise à l'autre.

</Callout>
